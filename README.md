# 求职材料（私有）

这个仓库和公开的 [mini-agent](https://github.com/xinx1999/mini-agent) 配套，
放**不适合公开**的内容：

- **`面试讲述稿.md`** —— 项目讲述稿，含面试话术与弱点题的应答
- **`学习路线.md`** —— 从现有项目到 AI 应用开发岗的 6 周学习规划

## 为什么单独放一个私有仓库

公开仓库是给面试官看的，这两个文件是给自己用的。

尤其讲述稿里有「如果被追问会不会 LangChain 就这样答」这类内容，
被面试官看到会暴露准备痕迹——**准备本身没错，但让人看到你怎么准备弱点题，会削弱效果**。
